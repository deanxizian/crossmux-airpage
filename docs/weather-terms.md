# 天气术语

显示名称参考 [Apple 官方简体中文天气图标说明](https://support.apple.com/zh-cn/guide/iphone/iph4305794fb/ios)，
底层仍使用 [Open-Meteo 的 WMO 天气代码](https://open-meteo.com/en/docs#weather_variable_documentation)。
本项目不使用 Apple Weather 数据或 WeatherKit 接口；这是一套展示文案映射。

## 代码与名称

| WMO 代码 | 页面显示 |
|---|---|
| `0` | 晴朗无云 |
| `1` | 大部晴朗无云 |
| `2` | 局部多云 |
| `3` | 多云 |
| `45` | 雾 |
| `48` | 雾伴雾凇 |
| `51`、`53`、`55` | 微雨 |
| `56`、`57` | 冻细雨 |
| `61`、`63`、`65` | 小雨、中雨、大雨 |
| `66`、`67` | 冻雨 |
| `71`、`73`、`75` | 小雪、中雪、大雪 |
| `77` | 米雪 |
| `80`、`81`、`82` | 阵雨、阵雨、强阵雨 |
| `85`、`86` | 阵雪、强阵雪 |
| `95` | 雷暴雨 |
| `96`、`99` | 雷暴伴雹 |
| 缺失或不支持的代码 | 未知 |

“微雨”对应 Drizzle，与“小雨”保留区分；“冻细雨”也不再合并为“冻雨”。
晴天和云量名称遵循 Apple 的表达，“局部多云”对应 partly cloudy，“多云”对应 overcast。
雨雪强度仍保留原来的细分，不将 `65`（heavy rain）直接写成具有日雨量等级含义的“暴雨”，
也不将 `75`（heavy snowfall）改成缺少风力依据的“暴风雪”。

Apple 的图标说明未单列的现象按 WMO 含义表达：`48` 同时说明雾和雾凇；
`96`、`99` 均保留冰雹信息，有限的显示空间不再细分这两档冰雹强度。
保留原始代码，图标仍按代码绘制，不根据中文文案猜测天气类型。

## 预报与缓存

页面显示包含今天的每日预报，并非当前时刻的实况。
日天气代码代表该日最显著的恶劣天气；“降水概率”取
`precipitation_probability_max`（当天各时段降水概率的最大值），不是雨量或下雨时间占比。

名称由 `app/weather_codes.py` 统一维护。实时采集、离线示例和缓存恢复均使用同一映射。
升级后会根据旧缓存中的代码重新生成名称，不必删除缓存或等待下一次天气采集；
温度、降水概率、采集时间和有效期保持不变。
